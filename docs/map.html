정리 맵이 있는 회의는 쟁점 → 주장 → 반론·근거 → 결론 순서로
논의가 진행된 시간대로 펼쳐집니다.

전사 .txt를 놓으면 원문이 열리고, 같은 이름의 정리 맵(.ibis.json)이 있으면 노드가 함께 펼쳐집니다.
음성(.m4a)을 같이 놓으면 재생 위치가 연결됩니다. 파일은 브라우저 안에서만 처리됩니다.

Anthropic API 키

정리 맵은 이 브라우저에서 직접 만들어집니다. 키는 이 브라우저에만 저장되고 Anthropic 외 다른 곳으로 가지 않습니다. 전사문은 정리를 위해 Anthropic에 전송됩니다.
키는 console.anthropic.com 에서 발급합니다.
